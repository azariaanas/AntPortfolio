Project Overview

A collaborative website project designed to educate users on Indonesia's 1998 Reformation Era, featuring historical timelines, key political shifts, national challenges, and a visual photo gallery wrapped in an accessible layout.

Roles & Responsibilities

  • Co-developed the website layout and content in a 2-person team.
  • Structured pages and styled the layout using HTML & CSS.
  • Implemented interactive features using JavaScript.

Technologies & Deliverables

  • Tech Stack: HTML, CSS, JavaScript
  • Result: An educational, well-structured, and interactive historical web portal.
