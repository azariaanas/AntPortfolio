Project Overview

A collaborative group website designed to showcase key information about Semarang City, including popular tourist destinations and rich culture, wrapped in a clean and accessible interface.

Roles & Responsibilities

  • Served as group coordinator during the project development phase.
  • Designed and developed the gallery and profile pages.
  • Structured the core website layout using HTML.
  • Styled and customized the header and footer sections using CSS.
  • Implemented JavaScript to enable interactive features across the site.

Technologies & Deliverables

  • Tech Stack: HTML, CSS, JavaScript
  • Result: An informative, well-structured, and user-friendly web portal.
