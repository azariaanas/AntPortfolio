Project Overview

A logo design project focused on gradient coloring techniques for a modern aesthetic, starting from initial hand-drawn sketches to detailed digital refinement in Ibis Paint.

Roles & Responsibilities

  • Created the initial hand-drawn sketches to define the logo concept.
  • Refined and vectorized the design details using digital drawing techniques.
  • Selected and applied complementary gradient color palettes.
  • Arranged overall visual elements and typography for a balanced composition.

Technologies & Deliverables

  • Tools: Ibis Paint X
  • Techniques: Digital illustration, vector refining, and gradient blending
  • Result: A polished, modern digital logo with vibrant gradient aesthetics.
