BomberCat Scratch

Project Overview

A simple Scratch-based action game titled BomberCat. Players control the bomber character to navigate freely around the arena, avoid enemy crabs (🦀), and strategically use bombs (💣) to defeat targets and score points.

Roles & Responsibilities

  • Developed the project independently from start to finish.
  • Built the core game logic, including enemy AI and bomb mechanics.
  • Designed the arena layout, character sprites, and UI elements.
  • Configured player movement controls, collision detection, and scoring system.

Technologies & Deliverables

  • Tech Stack: Scratch
  • Result: An interactive 2D arcade game featuring dynamic gameplay mechanics and high-score tracking.
